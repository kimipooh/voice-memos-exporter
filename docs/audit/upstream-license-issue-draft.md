## Issue body

Hi, and thank you for creating this useful Voice Memos exporter.

I noticed that `docs/CONTRIBUTING.md` says contributions are licensed “under its MIT License,” but the repository root does not contain a `LICENSE` file. I also checked the complete git history and found that a license file has never been added. GitHub does not currently recognize a repository license either: the repository API returns `null` for its `license` field.

Did you intend to license the project under the MIT License, and if so, would you consider adding the corresponding `LICENSE` file to the repository?

I am working on a fork with bug fixes for reproducible export failures, safer read-only database access, and more reliable command-line and graphical export paths. Before publishing or redistributing any modified version or build, I would like the upstream licensing terms to be explicit.

Thanks again for the project and for considering this request.
